# Bog orchid suitability - calibration report

> **SYNTHETIC DEMONSTRATION DATA - NOT A REAL RESULT**
>
> This run used fictional terrain, peat, habitat, watercourse and geology
> layers generated by `bogorchid.synthetic`, because the real datasets
> could not be reached. It demonstrates that the pipeline runs and that the
> weighting behaves as intended. It is not a statement about real ground and
> no site in it should be visited on its strength.
